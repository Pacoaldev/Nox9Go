# Branding source assets

Canonical NOX9GO mark files live here. The dashboard and tray ship **copies**:

| Source | Shipped as |
| --- | --- |
| `NOX9GO_logo.svg` | `web/public/favicon.svg`, `web/public/logo_9nox.svg` |
| `NOX9GO.ico` | `web/public/favicon.ico`, `cmd/nox9go-tray/tray.ico` |
| (derived) | `web/public/icons/icon-192.png`, `icon-512.png` |

Edit the sources here, then refresh the shipped copies (and rebuild `web` + binaries) when the mark changes.
